# BRIEF — Site oficial da GOIS GROUP (resumo fiel do pedido do cliente)

## ⚠️ FATO CONFIRMADO PELO CLIENTE (prioridade máxima — reconcilia todo o resto do brief)
"A gente é uma EMPRESA DE DESENVOLVIMENTO DE SITES."
Portanto:
- O ofício central da Gois Group é DESENVOLVER SITES (e, por extensão natural, a estrutura digital das
  empresas: sites, plataformas web, sistemas, produtos digitais). O visitante precisa entender em segundos
  que é aqui que se contrata o desenvolvimento do site/estrutura digital de uma empresa.
- Leia o restante do brief sob essa luz: "cria, desenvolve, estrutura e acelera empresas" = a Gois Group
  constrói a ESTRUTURA DIGITAL sobre a qual empresas existem, operam, vendem e crescem. "A estrutura por
  trás de diferentes negócios" é literal: o site é a estrutura. Ambição e escala vêm da qualidade de
  engenharia, design e método — não de fingir ser uma holding de investimentos.
- "Não construa como agência" continua valendo como LINGUAGEM: nada de tropos de agência (grade de
  thumbnails de portfólio, "somos apaixonados por", cards de serviço com ícones, "soluções digitais
  personalizadas"). A Gois Group se apresenta como uma casa de engenharia + design que constrói
  estruturas digitais com precisão — com a postura de quem constrói infraestrutura.
- O ECOSSISTEMA = as empresas cuja estrutura digital a Gois Group construiu e opera (clientes/parceiros) e
  eventuais empresas próprias — todas PLACEHOLDER até o cliente informar (não há nenhuma confirmada).
- Cases = sites/plataformas construídos, contados como prova (problema → estratégia → construção →
  lançamento → resultado). Todos PLACEHOLDER.
- Metodologia = o método proprietário de construir um site/estrutura digital (da leitura do negócio à
  evolução contínua pós-lançamento).
- Capacidades = o que é preciso para construir um site/estrutura digital completa (estratégia, arquitetura
  de informação, design de interface, identidade digital, engenharia front/back-end, performance, SEO,
  conteúdo, dados/analytics, integrações, automação/IA, evolução contínua) — agrupadas, não listadas.

## Missão
Projetar e desenvolver o SITE OFICIAL DA GOIS GROUP. Não é landing page genérica, não é site corporativo
tradicional, não é agência, não é consultoria genérica, não é portfólio freelancer, não é startup SaaS.
É uma EXPERIÊNCIA DIGITAL DE MARCA sofisticada, tecnológica, cinematográfica e memorável.

A Gois Group CRIA, DESENVOLVE, ESTRUTURA E ACELERA EMPRESAS. É a estrutura por trás de diferentes negócios.
Percepção desejada ao entrar: "É daqui que surgem empresas grandes."
Cadeia de percepção: GOIS GROUP → visão → estratégia → estrutura → tecnologia → execução → empresas → crescimento.
Transmitir AMBIÇÃO, CAPACIDADE DE EXECUÇÃO, PRECISÃO E ESCALA.
"Se eu quero desenvolver algo grande, essa empresa tem estrutura para isso."
NÃO dizer que é grande — DEMONSTRAR via design, arquitetura da informação, cases, números, empresas,
metodologia e qualidade da experiência. Nada de texto arrogante ou afirmação sem evidência. O design
transmite autoridade antes do copy.

## Referências de QUALIDADE (não de layout)
Apple, Stripe, Linear, Vercel, Palantir, A24, Pentagram, Resend, Ray-Ban, holdings internacionais, venture
studios. NÃO copiar layouts nem identidades. Linguagem própria.

## Direção visual
premium, minimalista, monumental, tecnológica, cinematográfica, precisa, elegante, contemporânea,
experimental na medida certa. Espaço negativo estratégico. "Cada pixel deliberadamente posicionado."
Não um carnaval de efeitos.
Base: preto profundo, off-black, grafite, branco, cinzas premium. UMA cor de destaque só se fortalecer a
identidade. Nada de cinco neons. Explorar: tipografia grande, contraste, espaço negativo, grids sofisticados,
linhas técnicas, microdetalhes, texturas discretas, profundidade, movimento, luz, sombras muito controladas.
Deve continuar elegante daqui a vários anos.

## Tipografia
Um dos principais elementos da identidade. Títulos grandes, fortes, bem compostos. Contraste entre headlines,
subheadlines, labels, informações técnicas, dados, números, descrições. Poucas palavras. Textos explicativos
claros.

## Hero
Excepcional; abertura cinematográfica da marca. Proibido: "Transformamos sonhos em realidade",
"Impulsionamos seu negócio", "Inovação que transforma", frases corporativas vazias.
Headline curta, proprietária, memorável. Direções (só direção): WE BUILD COMPANIES. / BUILD WHAT'S NEXT. /
FROM VISION TO COMPANY. / IDEAS BECOME INFRASTRUCTURE.
Pode usar: tipografia monumental, motion typography, background interativo, visual generativo, formas
abstratas, 3D sofisticado, grid dinâmico, partículas minimalistas, luz, profundidade, parallax discreto.
Efeitos NUNCA prejudicam conteúdo.

## Narrativa da Home (não Hero/Sobre/Serviços/Contato)
QUEM É → O QUE CONSTRUÍMOS → COMO CONSTRUÍMOS → EMPRESAS DO ECOSSISTEMA → NOSSA CAPACIDADE → NOSSA VISÃO →
POR QUE A GOIS GROUP → PRÓXIMO PASSO. Cada scroll revela uma nova camada da organização.

## Ecossistema (uma das seções mais importantes)
Mostrar que existe um ECOSSISTEMA. Cada empresa: nome, identidade, segmento, descrição, status, website,
principais números, case relacionado. Gois Group como estrutura central, empresas como partes de um
sistema: constelação / network / grid interativo / arquitetura modular / mapa visual / sistema orbital /
interface experimental — escolher a melhor metáfora. NÃO uma fileira genérica de logos.

## Metodologia
Explicar visualmente o processo (exemplo: IDENTIFY → DESIGN → BUILD → LAUNCH → SCALE). Não é definitiva:
criar metodologia PROPRIETÁRIA. O visitante precisa perceber que existe um SISTEMA.

## Capacidades
Strategy, Business Design, Branding, Product, Technology, Engineering, Growth, Marketing, Operations, Data,
AI, Automation — agrupar estrategicamente, mostrar como trabalham juntas; sem lista gigante.

## Cases
Provas, não cards de portfólio. Cada case: problema, oportunidade, estratégia, construção, empresa criada,
resultado, métricas verificáveis. NUNCA inventar clientes, faturamento, crescimento, usuários,
investimentos, resultados, empresas, parcerias. Sem dados → placeholders claramente identificados.

## Números
Seção de impacto com métricas reais (campos exemplo: Empresas desenvolvidas, Projetos lançados, Mercados,
Usuários impactados). NÃO INVENTAR; sinalizar claramente onde inserir.

## Sobre
Não é "Sobre nós" tradicional. Por que existe, visão, como pensa, o que acredita sobre criação de empresas,
modelo, futuro. Pensamento, convicção, filosofia, visão de longo prazo.

## Motion
Parte da identidade: scroll reveals, parallax, mask reveals, text reveals, transições, microinterações,
hover, movimentos de câmera, elementos seguindo cursor, mudanças de iluminação, transições entre seções.
Extremamente suave; comunica qualidade; nunca demo de efeitos.
Cursor custom só se melhorar genuinamente. Cards reagem sutilmente. CTAs magnetic hover muito discreto.
Imagens revelam informação na interação. Links com animação própria.
Transições entre páginas (Home, Companies, Cases, About, Contact): elegantes, reforçam continuidade,
RÁPIDAS — nunca fazer o usuário esperar.

## Páginas
HOME, COMPANIES (ecossistema completo), COMPANY DETAIL (uma por empresa), CASES, CASE DETAIL (storytelling),
ABOUT (visão, história, filosofia), CONTACT (novos negócios, parceiros, oportunidades). Só adicionar outras
se realmente necessárias.

## Header / Footer
Header extremamente limpo: logo, navegação objetiva, CTA estratégico, transformação sutil no scroll, pouco
espaço. Footer = encerramento da experiência, fechamento visual forte, frase final de filosofia; navegação,
redes oficiais, contato, informações legais, empresas, copyright — SOMENTE informação real.

## Responsivo
Desktop, notebook, tablet, mobile com experiências específicas. Mobile não é versão quebrada. 3D
simplificado, sem interações de cursor, grids reorganizados, tipografia fluida, motion reduzido, ainda premium.

## Performance
Sem JS desnecessário, bibliotecas gigantes, vídeos enormes, WebGL sem propósito, efeitos pesados, imagens
sem otimização, layout shift. Lazy loading. Animações em transform/opacity. Fallback se WebGL/3D.

## Acessibilidade
HTML semântico, contraste, teclado, focus states, ARIA quando necessário, alt text, áreas clicáveis,
prefers-reduced-motion. Utilizável sem animações.

## SEO
title, meta description, Open Graph, Twitter/X cards, canonical, sitemap, robots, schema markup, headings
semânticos, URLs limpas.

## Copy (escrever a copy completa)
Tom: confiante, preciso, ambicioso, sofisticado, direto, inteligente. Sem arrogância, sem promessas
impossíveis, sem buzzwords. Proibido: "Inovação e excelência", "Transformamos ideias em realidade",
"Soluções personalizadas", "Seu sucesso é nosso sucesso", "Impulsionamos negócios", "Conectando pessoas e
oportunidades". Cada frase precisa dizer algo.

## Não criar
landing genérica, template SaaS, design de agência, cards arredondados iguais, gradientes aleatórios,
glassmorphism em tudo, glow excessivo, bento grid sem motivo, animações excessivas, frases vazias, stock
photos clichês, executivos apertando mãos, ícones genéricos em cada seção. Não copiar tendências.

## Implementação
Componentes reutilizáveis; design tokens (cores, tipografia, spacing, radius, shadows, motion, breakpoints);
código organizado; sem dependências desnecessárias; estrutura correta de componentes/páginas/layouts/assets/
animações.

## Regra de ouro
Cada elemento visual: "fortalece a identidade da Gois Group ou só parece bonito?" Se não fortalece, REMOVA.
Cada animação: "melhora a experiência ou só demonstra tecnologia?" Se não melhora, REMOVA.

## Resultado final — o visitante sai entendendo
1. A Gois Group constrói e desenvolve empresas.
2. Existe estratégia, design, tecnologia e execução por trás desse processo.
3. Para uma empresa ambiciosa a ser construída/desenvolvida, a Gois Group deve estar entre as consideradas.
Parecer MAIOR por qualidade, clareza, provas e consistência — não por exagero de copy.

# FATOS E RESTRIÇÕES DO PROJETO (definidos pelo orquestrador)

- Dados reais disponíveis sobre a Gois Group: APENAS o nome "Gois Group" e o posicionamento acima.
  Não há: nomes de empresas do grupo, segmentos, números, cases, clientes, fundadores, ano de fundação,
  cidade, e-mail, telefone, redes sociais, CNPJ. Busca web não encontrou a empresa (só homônimas sem
  relação — NÃO usar). Tudo isso vira PLACEHOLDER claramente identificado, centralizado num arquivo de
  conteúdo, com um estado visual "dado pendente" que ainda pareça deliberado e premium.
- Metodologia, capacidades, filosofia, manifesto e copy institucional PODEM ser escritos (são posicionamento,
  não dados factuais) — mas sem afirmar fatos (anos de mercado, quantidade de empresas, resultados).
- Idioma: pt-BR (lang="pt-BR"). URLs limpas em pt-BR: /, /empresas, /empresas/[slug], /cases, /cases/[slug],
  /sobre, /contato.
- Stack: Next.js 16 (App Router) + React 19 + TypeScript, `output: 'export'` (site estático, hospedável em
  qualquer lugar). CSS puro com custom properties (tokens) + CSS Modules. SEM GSAP, SEM three.js, SEM
  framer-motion, SEM Tailwind: motion com CSS + IntersectionObserver + requestAnimationFrame; visual
  generativo com Canvas 2D ou SVG (WebGL só se indispensável, com fallback). Transições de página via
  View Transitions API (document.startViewTransition) com fallback. Fontes self-hosted via @fontsource
  (npm) carregadas com next/font/local — escolha fontes disponíveis no Google Fonts / Fontsource.
- Sem fotos/stock. Visual feito de tipografia, linhas, grid, luz, geometria gerada por código.
- Formulário de contato: site estático — envio por endpoint configurável (env) com fallback mailto;
  e-mail é placeholder até ser informado.
