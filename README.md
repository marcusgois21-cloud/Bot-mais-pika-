# Site institucional — Vereador Wellington Neim

Site oficial do vereador Wellington Neim, presidente da Câmara Municipal de
Ponte Nova (MG), no ar em:

**https://wellington-neim.higgsfield.app**

- Conceito: "estilo clássico de site político (referência aprovada pelo cliente): azul e branco, Poppins, distintivo de campanha.
- Conteúdo 100% baseado em fontes públicas (TSE, Câmara Municipal, imprensa local)
- `site-wellington-neim/` guarda o brief de design, o código das seções e os
  recursos visuais (retrato, cartão de compartilhamento, favicon)

Pendências aguardando o cliente: número de WhatsApp do gabinete (o botão
"Fale comigo" aponta para o Instagram por enquanto), fotos extras e slogan.
